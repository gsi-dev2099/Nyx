# Reglas Inquebrantables de Documentación
1. Documentar el porqué (ADRs).
2. Todo problema importante termina en la Knowledge Base (KB).
3. Diferenciar mitigación de solución definitiva.
4. La KB debe ser accionable.
5. Markdown para conocimiento, HTML para lo visual.
6. Los documentos se enlazan entre sí.
7. NUNCA secretos reales en docs/.
8. Encabezado ISO en todo documento (Código, versión, fecha, autor).
9. Actualizar la documentación en el mismo PR que el código.
10. La documentación crece con el proyecto.
